1→DATA PRODUCT|The output of a data pipeline that delivers value: dashboards, datasets for ML models, data within applications, or shared data for other teams.|data_products
2→SECURE DATA SHARING|Snowflake feature that lets providers share live data with consumers without copying it. Consumers query the provider's data directly in their own Snowflake account.|data_products
3→SNOWFLAKE MARKETPLACE LISTING|A published data product on Snowflake Marketplace. Providers list datasets; consumers discover and access them. Data remains with the provider — consumers get a live, read-only view.|data_products
4→STREAMLIT IN SNOWFLAKE|A way to build and host interactive Python data apps directly inside Snowflake. Apps run within a Snowflake account and can access Snowflake data without external infrastructure.|data_products
5→SNOWFLAKE NATIVE APPLICATION|An application built with the Snowflake Native App Framework that can be listed on the Marketplace and installed into consumer accounts. Unlike Streamlit apps (account-only), native apps run within the consumer's own Snowflake account.|data_products
6→NATIVE APP VS STREAMLIT|Streamlit in Snowflake: interactive apps scoped to one account. Native Apps: packaged applications deployable to any consumer's Snowflake account via the Marketplace. Native apps can include Streamlit UIs plus logic, stored procs, and UDFs.|data_products
7→SNOWFLAKE CONTAINER SERVICES|Snowflake feature that allows running containerized workloads (Docker images) inside Snowflake. Used within Native Apps to run custom runtimes or microservices alongside Snowflake data.|data_products
